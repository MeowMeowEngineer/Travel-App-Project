## 8. 다시 돌리는 법
```bash
node tools/serve_preview.mjs --data data/incheon --out dist-qa-final --port 8799   # 키는 .env의 ANTHROPIC_API_KEY 한 줄
python tools/perf_check.py --out dist-qa-final --block-external --pages / /places/ /cafes/ /map/ "/search/?q=교동도" /search/
python -m pytest -q && npm test
```
Playwright는 `https://incheon.webforai.kr/**`를 `http://127.0.0.1:8799`로 돌려 실제 도메인에서 연다(카카오 지도). 스크립트는 저장소에 넣지 않았다.
